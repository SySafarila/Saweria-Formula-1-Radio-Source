# Saweria Formula 1 Radio Source

A source code for this repository: https://github.com/SySafarila/Saweria-Formula-1-Radio

# Catatan

Untuk versi bagibagi.co, silahkan jalankan program berikut dengan menekan `Windows + X`, kemudian tekan tombol `R`, dan masukan kode di bawah lalu tekan `Enter`

```sh
"C:\Program Files\obs-studio\bin\64bit\obs64.exe" --disable-web-security --disable-site-isolation-trials
```

# Untuk development
```sh
chrome.exe --disable-web-security --user-data-dir="C:\chrome_dev"
```
